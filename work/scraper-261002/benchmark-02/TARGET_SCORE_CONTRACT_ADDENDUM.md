# Prospective No-Omission Contract

Freeze this addendum, score_contract.py, runner.py and the complete tooling seal
BEFORE any new source-reference, source-host, host-sense, target-reference or
target-host reader. There are exactly 200 prospective directed obligations:
50 source units selected before host answers, four target languages each, 20
directions of 10 obligations. No outcome changes this denominator.

A strict correspondence success requires an actually captured normal task,
independently verified source-sense equivalence, exactly one normal persisted
relation for that acquired subject and frozen host sense, and exact kind/vector
agreement with a pre-frozen meaningful alternative. Only lexical, paraphrase,
and reference kinds can succeed. An omitted or unresolved relation remains a
gap, even if its type/context-anchor classification matches the reference.
Pipeline misses, missing/ambiguous relations and source-sense mismatch score
zero. Classification matches are diagnostics, never correspondence successes.

The authoritative score is only benchmark-02/scores/report.json, generated by
the new runner using the pure prospective evaluator. No omission-credit score
is generated or inherited. The source gates stay 90% overall and 85% in every
language, on independently frozen meaningful units (at least 100), from normal
accepted receipts. Target gates stay 90% overall and 80% in every direction.
The released-baseline comparison uses the unchanged identical common fixed
context lexical-scalar metric on the same 200 obligations for both versions,
with at least 20 percentage points improvement. Nonlexical blank scalar output
is not scalar success for either version. Normal receipt/replay, consumers and
separate-process reload gates remain mandatory.

This tooling does not read or use the original trial's semantic results. Any
shortfall is FAIL; any failed/partial stage is retained under a permanent STOP.
No relabeling, reranking, product repair against these labels, retrial in place,
or substitution of independent reference meaning for host meaning is allowed.
