## Independent Agents

Use fresh `fork_turns="none"` agents. Source reference agents receive only their
own source reference TXT and general contract. Separate source hosts receive only
their own concatenated unchanged normal source TXT. No source host sees source
reference labels, source selection, another language, or targets. All five
reference originals freeze and validate exact grounding before host submissions.
Source hosts must use the existing supported typed `subjects` form for every
specific meaningful occurrence/layer. Legacy `terms` are valid optional normal
observations, but are not substitutes for an exact occurrence vector; retain
them as separate diagnostics rather than guessing their repeated geometry from
the reference oracle. This is an exact occurrence-vector source recall benchmark,
not a schema-neutral scalar source recall benchmark.
Hosts return normal agent_review JSON/TXT judgments, submitted unchanged through
`ar.parse_judgments_text` and `ar.submit_judgments`. Continuation/audit work, if
needed, also uses actual normal follow-up packets, with the same isolation.
Completion declarations bind packet and raw-answer SHA256 and identify all
forbidden input classes as unread. Declarations are provenance, not proof of
semantic accuracy. Retain accepted receipt, submit result, inert replay and state
hash at every submission. Never manually accept a reference source subject.

## Fixed Targets

Before examining source-host answers, hash every independent source reference
unit by SHA256(`261002-target|` + canonical JSON of language, story_key,
evidence_id, segments). Select the first five by hash per family per language,
breaking ties by canonical vector. This is ten source units per language, fifty
overall, four target languages each: exactly 200 directed obligations. Fewer than
five natural reference units in any family/language invalidates the trial.
Only exact units genuinely acquired by normal accepted source receipts may have
actual generated occurrence tasks captured. A missing source, absent task,
unsupported task or unclosed debt remains `pipeline_miss`, never replaced by an
easier unit and never fabricated from a reference-seeded source acceptance.

After normal source acquisition, a source-only host sense packet contains that
host's own acquired vectors and original source rows, without references or any
target. Freeze its independently written contextual meanings before target packet
read. The host sense JSON is {"language":"en","units":[{"subject_id":"...",
"meaning":"source-only contextual meaning","rationale":"source evidence"}]};
include exactly every normally acquired subject once. Target hosts receive only
their own frozen host meanings, never the independent reference meaning oracle.
Target reference agents instead receive separately frozen independent source
meanings and the host meanings to assess `source_sense_equivalent` before any
target-host answer. They independently verify the host meaning against source
text; a source sense mismatch is an end-to-end miss, not repaired by substituting
the reference sense. Target reference agents and target hosts are separate fresh
agents. Give each actual normal occurrence TXT and its separate meaning packet;
include no target candidates or labels.
Reference readers return every task's typed exact target vector and contextual
semantic rationale, optionally several genuinely equivalent boundary/type
alternatives pre-frozen before host answers. A lexical direct conventional
realization may differ grammatically from the source. Paraphrase requires actual
content reformulation. Reference requires contextual referent identity, not just
same topic. Omitted requires a justified absence within the examined scope;
unresolved is never a correct realization for the strict score. Never relabel a
vector after seeing host output. Empty-vector omitted references use the full
examined target region as a context anchor in ordinary product judgments, not as
an expression. Broader public expansion/follow-up tasks retain the exact source
and source-only sense. Freeze new independently read alternatives before their
corresponding host follow-up answer, not after seeing that answer.

Target reference JSON per source language is
{"language":"en","records":[{"obligation_id":"...","source_sense_equivalent":true,"alternatives":[
{"kind":"lexical|paraphrase|reference|omitted","target_segments":[{"start":0,
"end":1,"exact":"..."}],"rationale":"positive component and boundary evidence"}]}]}.
Reference vectors must be grounded in the actual captured task windows. Missing
aligned views never delete obligations: reference readers may examine the actual
registered raw target page in an explicitly reference-only context, while the
host pipeline still has a miss/debt and no fabricated task. Omitted
means an examined context anchor, not empty product segments. Pipeline misses
have no task or alternatives but stay in the scoring denominator.

Export unchanged `05d2749` sekaisync code and pyproject with git archive into this
benchmark's released-baseline directory. Run it in a separate process with only
the exact ten fresh pages as input, no references, selected units, candidate

match. Report scalar/contextual correctness separately from representation gaps.

points improvement using the same common scalar/contextual metric and the same
fixed 200 obligations for both implementations. Nonlexical blank scalar results
are not lexical successes for either implementation. Exact typed kind/vector
compliance remains a separate current-product release gate.

Score exact source recall across all independently labeled units and per language
using accepted normal receipts only. Target strict correctness requires source
acquisition, actual generated task, accepted normal typed relation and exact
kind/vector agreement with a pre-frozen meaningful alternative and independently
verified host source-sense equivalence. Preserve all
pipeline misses in the fixed denominator. Also exercise ordinary `term_penetrate`
and `query` consumers and a separate-process reload of the same persisted stores;

or non-inert replay is a protocol failure, not a semantic pass.

PASS requires source >=90% overall and >=85% in each language; target >=90%

inert replays, consumer queries and reloads pass. A measured shortfall remains
